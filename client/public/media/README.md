# Replaceable website media

Drop homepage.webp (preferred), homepage.jpg or homepage.png here to replace the homepage still on the next deployment. Optional homepage.mp4 adds a muted looping video with the still as its poster. Keep both files for reduced-motion visitors. Recommended still: 2400 by 1350 pixels, under 500 KB. Recommended video: 8 to 15 seconds, no audio, 1920 by 1080, ideally under 5 MB. Keep the left half quiet for the headline. Do not put words or logos into the photo.

For article images, add a descriptive file here and set that article's Sanity heroImageUrl to /media/filename.webp. Alternatively use an HTTPS image URL in Sanity. The next successful website build reads the published article. SVG editorial defaults remain in /img/editorial.

Files in this folder are public. Do not place confidential documents or raw client material here.
